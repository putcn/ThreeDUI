# Component guide

GlassUI components are Vue components, but they render into GlassUI's three.js scene. Import them from `@glassui/vue`. The [generated manifest](../packages/vue/manifest.json) is the detailed API reference: it includes every exported component's props, events, slots, models, examples, and common mistakes. The [interactive gallery](http://127.0.0.1:5176/?scene=gallery) demonstrates the core controls.

## Choose a container

| Need | Component | Rule |
| --- | --- | --- |
| A camera-facing overlay | `<Surface layer="screen">` | Use `center`, `fill`, or `left`/`top`; sizes are screen points. |
| A panel in the world | `<Surface layer="world">` | Use `position`/`rotation` in world units and `ptPerUnit` for scale. World is the default layer. |
| A navigable spatial workspace | `<Space>` with direct `<Block>` children | `Space` lays out Blocks and can control camera focus. Names must be unique. |
| A raised section inside a Block | `<Card>` | Use for grouped content; the glass sits in front of the Block. |

`Surface` does not draw a Vue host node. Put `tw`, `class`, and `style` on a child `Box` or `Stack`, not on `Surface`. `Block` accepts layout style for its content box. [The spatial guide](./spatial-ui.md) explains the different coordinate systems.

## Build a view

| Group | Components | Gallery section |
| --- | --- | --- |
| Layout and display | `Box`, `Stack`, `Text`, `Icon` | `primitives` |
| Actions | `Button` | `buttons` |
| State | `Switch`, `Checkbox` | `toggles` |
| Entry | `Input` | `inputs` |
| Modal flow | `Dialog` | `dialog` |
| Fused glass controls | `GlassContainer` | `containers` |
| Spatial data | `Viewport3D`, `BarChart3D`, `SurfaceChart3D`, `BarMatrix3D`, `LineChart` | [spatial app](http://127.0.0.1:5176/?scene=spatial&stage=overview) |

Choose `@press` for buttons, `v-model` for `Input`, `v-model:checked` for switches and checkboxes, and `v-model:open` for dialogs. Keep a `Dialog` mounted while closing if you want its exit animation. `Text` takes a `value` prop; `Stack` and `Box` handle layout. `tw` accepts GlassUI's own documented utility grammar, not arbitrary CSS or the entire Tailwind catalog.

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Surface, Stack, Text, Input, Switch, Button, Dialog } from '@glassui/vue'
const name = ref('')
const remember = ref(false)
const open = ref(false)
</script>

<template>
  <Surface layer="screen" center :width="420" :height="380" background="glass" :radius="28">
    <Stack tw="p-6" :gap="16">
      <Text value="Welcome" size="2xl" />
      <Input v-model="name" placeholder="Your name" />
      <Switch v-model:checked="remember" label="Remember me" />
      <Button label="Continue" variant="glassProminent" @press="open = true" />
      <Dialog v-model:open="open" title="Hello">
        <Text :value="name || 'Guest'" />
      </Dialog>
    </Stack>
  </Surface>
</template>
```

For names, defaults, and accepted values, use the manifest rather than guessing from HTML or standard Vue libraries. It is regenerated by `pnpm manifest`. Implementation examples in [`examples/playground/src/gallery`](../examples/playground/src/gallery) and [`examples/playground/src/wms`](../examples/playground/src/wms) show practical combinations.
